Before feature extraction, intensity processing was performed separately for each FLAIR and postcontrast T1-weighted image. We calculated the first and 99th percentiles from finite voxel values strictly greater than zero, using linear percentile interpolation. This support region was determined from the image rather than from the annotation mask. Equation 1 defines the scaled intensity u, with x denoting a supplied voxel value and the percentile symbols denoting the corresponding image-specific reference values. The transformation was applied to all ROI voxels, including voxels whose original intensity was zero. Values below zero or above one after scaling were retained. The unclipped transformation was adopted after a technical pilot showed that percentile clipping merged some higher ROI intensities; it was an engineering amendment made after observing processing diagnostics, without using classification performance to choose the method. Image-specific parameters were calculated without pooling information across patients or examinations. Degenerate percentile ranges were treated as processing failures.

Four features were calculated from each sequence, yielding eight MRI inputs: mean, population standard deviation, Shannon entropy and three-dimensional gray-level co-occurrence matrix contrast. Mean and standard deviation used the scaled ROI intensities directly, with the voxel count N as the denominator in Equation 2. Entropy and texture calculations used fixed-bin-number discretization following the Image Biomarker Standardization Initiative (IBSI) framework (4). For each sequence and examination, a and b denoted the minimum and maximum scaled intensities within the full ROI. Equation 3 assigned these values to 32 bins; the minimum entered bin 1 and the maximum entered bin 32. In Equation 4, each bin probability is the fraction of ROI voxels assigned to that bin, and bins with zero probability do not contribute. Entropy was expressed in bits using base-2 logarithms. Constant ROI intensities were treated as processing failures. The feature set and bin count were fixed before batch extraction, without outcome-based feature selection.

The gray-level co-occurrence matrix (GLCM) was constructed from neighboring voxel pairs contained entirely within the ROI. We used 13 undirected offsets representing the 26 immediate neighbors at a Chebyshev grid distance of one supplied voxel. This distance referred to the file grid and was not interpreted as one millimeter. For each offset in the set D, the directional count matrix C recorded pairs with bin indices i and j. Equation 5 defines the pooled symmetric counts S and the normalized matrix P. Contrast was calculated from this single matrix as shown in Equation 6 (4). We combined counts before calculating the feature, without averaging separate directional contrast values or applying distance weights. Each sequence produced one contrast value. A region with no valid neighboring pairs was recorded as a processing failure. We checked the implementation with small arrays having known results; this did not establish complete IBSI benchmark validation.
