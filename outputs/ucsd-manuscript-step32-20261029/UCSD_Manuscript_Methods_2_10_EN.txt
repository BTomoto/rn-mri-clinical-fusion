Analyses were implemented in Python 3 using scikit-learn 1.8.0 (5), NumPy 2.3.5, pandas 2.2.3, SciPy 1.17.0 and Matplotlib 3.10.8. Jupyter notebooks for feature extraction, model evaluation and sensitivity analyses were executed through an in-process ipykernel 7.4.0 kernel, with code hashes and execution receipts retained. The public project repository (https://github.com/BTomoto/rn-mri-clinical-fusion) contains code, derived data, OOF probabilities, fold assignments and analysis locks linking inputs, protocols and code by SHA256 checksums. Model analyses can be rerun from the saved feature tables without downloading images again. Re-extracting features requires the image files: 18 inputs are included as repository samples, whereas 528 additional inputs were archived separately. Source manifests provide acquisition URLs and checksums, and an archive restoration script verifies the archive and its extracted members. The saved restoration receipt records successful verification of all 528 additional files; access to the stored archive requires its holder’s account, with public acquisition URLs providing an alternative route. Sample size was determined by eligible linked examinations with available inputs, without a prospective sample-size calculation.
